## OpenAPI 운영 기준

- HTTPS POST 방식
- UTF-8 JSON 입출력
- JSON 파일 업로드 방식은 지원하지 않음
- 검색 API 1회 최대 10,000건
- 페이지네이션 최대값 20,000
- 20,000건 초과 시 기간·언론사·분류를 나눠 조회
- 별도 시간·일별 호출 횟수 제한 없음
- Python 등 프로그램을 이용한 정기 자동 조회 가능
- 신규 기사 알림 기능은 별도 제공하지 않음
- AND, OR, NOT, 괄호 검색식 지원
